ugit就是个git的可视化管理工具，不用一直敲命令（能提交到本地仓库，然后再推送到远程仓库）


提交流程：
0.先获取最新的仓库（fetch，别人可能有提交）
1.从变更区添加到待提交区，确认待提交内容
2.写提交日志
3.提交到本地仓库
4.推送到远程仓库

备注：
检查更新（fetch）就是获取分支目录
更新（pull）是把当前分支拉到最新

同步流程：
0.先获取最新的仓库（fetch，别人可能有提交）
1.先确认哪个分支合并到哪个分支         （把有的合并到没有的）
2.比如  A合并到B
3.先检出B,然后右键A 选择把A合并到B
